# 02 Add and remove tags on a contact

Status: open
Blocked by: 01

## Goal
A user can add tags to a contact and remove them from the contact view, and the tags show on each row of the contact list.

## Acceptance
- [ ] Contact view has an input to add a tag and a control to remove each tag.
- [ ] Server validation errors show to the user.
- [ ] Contact list rows show each contact's tags.
- [ ] `docs/` describes the tag data model and behavior.
- [ ] `npm run typecheck`, `npm run lint` and `npm test` pass.
