# Ryan, let's talk

The user wants to discuss, not build. Answer and discuss only: write no spec, ticket, plan, file or code change. Read the code when it helps the answer.

When the discussion ends, ask once in one line what to do with it: park it (`ryan-remember`), plan it (`ryan-plan`), record a settled decision under "Decisions" in `AGENTS.md`, or nothing. "Nothing" is a normal answer.
